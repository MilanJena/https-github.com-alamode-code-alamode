Download
========

The recommended way to obtain ALAMODE is from the `GitHub repository <https://github.com/alamode-code/alamode>`_,
which always has the latest version.

With git (recommended)
----------------------

Clone the repository::

    $ git clone -b master https://github.com/alamode-code/alamode.git
    $ cd alamode

The branch ``master`` holds the latest release. To use exactly the 2.0.0 release,
run ``git checkout v2.0.0``.

To update to the latest version later, run ``git pull`` in the same directory.

Without git
-----------

* **Latest version** — open the `repository page <https://github.com/alamode-code/alamode>`_,
  select the branch, and choose *Code* → *Download ZIP*.
* **Release versions** — download an archive from the `GitHub releases page <https://github.com/alamode-code/alamode/releases>`_.

Alternative: SourceForge
------------------------

Release packages are also available at https://sourceforge.net/projects/alamode.
They are not updated as often as GitHub, so use them only if GitHub is not accessible.
